# 🧠 Fetal AI Using Machine Learning to Predict and Monitor Fetal Health

## 📌 Project Overview
This project focuses on leveraging **Machine Learning and Artificial Intelligence** techniques to **predict and monitor fetal health conditions** using clinical and physiological data.  
The system aims to assist healthcare professionals by providing **early risk detection**, improving prenatal care, and reducing complications during pregnancy.

---

## 🎯 Objectives
- Analyze fetal health data to identify risk patterns  
- Build predictive machine learning models for fetal condition classification  
- Monitor fetal health indicators efficiently  
- Support early medical intervention and decision-making  

---

## 🗂️ Dataset Description
The dataset includes clinical and fetal health parameters such as:
- Fetal heart rate (FHR)  
- Accelerations  
- Decelerations  
- Uterine contractions  
- Short-term variability  
- Long-term variability  
- Baseline fetal heart rate  

### 📌 Target Variable
- **Normal**
- **Suspect**
- **Pathological**
